# Codebase Research Loop 演示脚本

目标时长：100 秒。只展示真实数据库中的项目与报告，不现场调用不稳定的外部 LLM。

## 0:00-0:12 项目定位

口述：

> Codebase Research Loop 是一个只读工程调研工作台。它把陌生仓库的采集、分析、证据校验、报告和人工评审串成一个可恢复的后台任务。

画面：`/projects` 项目列表。

## 0:12-0:30 输入与采集

画面：进入项目，切换“输入源”和“采集”。

口述：

> 输入源支持本地目录、公开仓库、网页和文档。采集阶段按路径策略跳过 `.env`、依赖目录和大文件，并把跳过原因写入审计结果。

## 0:30-0:55 可恢复 Loop

画面：切换“调研过程”，指出 9 个节点、checkpoint ID 和运行时间线。

口述：

> 后端用 LangGraph StateGraph 编排 9 个节点，每一步 checkpoint 持久化到 MySQL。用户暂停或进程中断后，可以从同一个 thread 恢复。

## 0:55-1:15 质量与证据

画面：展示质量面板、发现页和风险页。

口述：

> 终止状态不由 LLM 决定。确定性 verifier 检查结构、证据引用、代码覆盖和风险缓解；LLM 复核失败时回退到确定性结果，不影响主链路。

## 1:15-1:35 报告与评估

画面：展示报告页和 `/evaluations`。

口述：

> 系统能导出 Markdown 和 PDF 调研包。仓库里有 8 个确定性评估用例，其中 3 个是扫描回归，5 个是调研档位 fixture，用于防止结构回归。

## 1:35-1:40 收尾

口述：

> 当前演示使用确定性路径，外部 LLM 是可选增强。这样展示的是系统本身的编排、证据和校验能力。
